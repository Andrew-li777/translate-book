# 未来发展

已实现能力之外的演进方向（按价值排序）。

## 一、翻译体验

- **逐块对照阅读增强**：同步滚动已做；可加——锚点跳转、字数/进度统计、原文/译文逐行高亮对应
- **术语表批处理**：批量导入/导出、跨书共享术语表模板
- **翻译记忆**：已译句子缓存，重复片段复用译文（长系列书加速）

## 二、产品化

- **用户系统**：当前是单账号 + 应用层两档鉴权（游客只读 / 管理员全功能，见问题 #23），可扩展多用户（各自书库、按用户配额）
- **在线阅读器**：EPUB 浏览器内翻页阅读（当前是 markdown 渲染 + 下载成品）
- **翻译风格预设**：正式/通俗/学术预设，一键应用到整书
- **双语导出**：对照式 EPUB/PDF（原文+译文并排）

## 三、工程化

- **CI**：book/tests 有上游测试，可接 GitHub Actions 跑回归
- **Docker 化**：整栈容器化（web + 引擎 + Caddy），便于迁移
- **全文索引升级**：当前搜索是文件级 grep 聚合，量大后可换 SQLite FTS5
- **监控告警**：任务失败/磁盘水位告警推送（QQ/Telegram）
